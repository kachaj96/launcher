# Launcher

Minimalistyczny launcher na Androida. Plan: `docs/PLAN.md`, zasady dla Claude Code: `CLAUDE.md`.

## Instalacja na telefonie

1. GitHub → zakładka **Actions** → ostatni zielony przebieg **Build APK** → sekcja **Artifacts** → pobierz `launcher-debug-<nr>`.
2. Rozpakuj ZIP i otwórz `app-debug.apk` na telefonie. Zezwól na instalację z tego źródła, jeśli Android zapyta.
3. Otwórz aplikację **Launcher** i stuknij **Ustaw jako domyślny**.

Powrót do One UI Home: Ustawienia → Aplikacje → Wybierz aplikacje domyślne → Ekran startowy.
